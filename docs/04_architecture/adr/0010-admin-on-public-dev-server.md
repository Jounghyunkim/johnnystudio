# ADR-0010: 인터넷에 연 개발 서버(PUBLIC_URL)에서도 작품 관리 화면을 켠다

- **상태**: 채택됨
- **날짜**: 2026-11-09
- **관련**: [ADR-0009](0009-local-portfolio-manager.md) 결정 4 ("PUBLIC_URL 로 띄울 때는 관리 서버를 켜지 않는다")를 대체한다. [기능 명세](../../02_planning/features/portfolio-manager.md)

## 맥락

- 사용자 요청 (2026-11-09): "PUBLIC으로 동작 시켜도 관리자 메뉴 들어갈 수 있도록 수정해 줘."
- `dev.sh` 를 `PUBLIC_URL=http://johnnyhouse.iptime.org:3000` 처럼 띄우면 공유기 포트포워딩으로 인터넷에서 개발 서버에 닿는다. ADR-0009 는 이때 관리 서버를 끄게 했다 (`ADMIN=1` 로만 켤 수 있었다).
- 공개 주소는 보통 **http** 다. 관리 토큰(`Authorization` 헤더)이 암호화되지 않은 채 오가므로, 오가는 길(공용 와이파이 등)에서 엿볼 수 있다.
- 토큰을 가진 사람은 `content/assets` 를 고치고 이미지·다운로드 파일을 올릴 수 있다. 사람이 그것을 모르고 배포하면 공개 사이트가 바뀐다.
- 토큰은 256비트 무작위 값이라 추측으로 맞힐 수는 없다. 문제는 "새어 나가는 것"이다.

## 검토한 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 지금처럼 끄고 `ADMIN=1` 로만 켠다 | 가장 안전 | 사용자가 원하는 동작이 아니다. 켜는 방법을 모르면 막힌다 |
| B. 기본으로 켜고, 일반 모드와 똑같이 둔다 | 단순 | http 로 새어 나간 토큰이 다음 실행에도 계속 유효하다. 운영 다운로드 폴더에 바로 쓸 수 있다 |
| **C. 기본으로 켜되, 공개 모드에서만 위험을 줄인다** | 원하는 동작 + 새어 나가도 피해가 짧고 좁다 | 공개 모드에서는 주소를 북마크해 둘 수 없다 (실행마다 토큰이 바뀐다) |

## 결정

`PUBLIC_URL` 로 띄워도 관리 서버를 켠다 (끄려면 `NO_ADMIN=1`). `ADMIN=1` 은 없앤다. 공개 모드에서는 다음을 함께 한다.

1. **토큰은 실행할 때마다 새로 만들고 파일에 남기지 않는다.** `dev.sh` 를 끄면 그 토큰은 쓸 수 없다. 일반 모드의 `.local/admin-token` 은 건드리지 않는다.
2. **다운로드 파일은 운영 폴더(`/opt/johnnystudio/files`)에 바로 쓰지 않고 `.local/files` 에 둔다.** 운영 폴더로 옮기는 일(`install` 명령)은 사람이 한다. `JOHNNYSTUDIO_FILES_DIR` 을 직접 주면 그것을 따른다.
3. 토큰이 틀린 요청은 관리 서버가 터미널에 알린다 (1분에 한 줄, 누적 횟수·주소·`X-Forwarded-For`). 일반 모드에서도 같다.
4. `dev.sh` 의 인터넷 공개 경고에 "관리 화면도 열린다, http 면 토큰이 평문으로 오간다, 공용 와이파이에서 쓰지 말고 끝나면 끈다"를 더한다.

관리 서버는 여전히 127.0.0.1 에서만 듣는다. 인터넷에서는 Next 개발 서버의 `/__admin/` 을 거쳐서만 닿는다.

## 결과

- **좋아지는 점**: 밖에서(휴대폰 등) 개발 서버를 열어 둔 채 작품을 고칠 수 있다. 토큰이 새어도 그 실행이 끝나면 쓸 수 없고, 운영 다운로드 파일은 바로 바뀌지 않는다.
- **감수할 점**: http 공개 주소에서는 토큰이 평문으로 오간다 (HTTPS 가 아니면 막을 수 없다). 공개 모드에서는 실행할 때마다 터미널의 새 주소로 들어가야 한다. 초안 공개·회원 API 메일 같은 공개 개발 서버의 원래 위험은 그대로다.

## 재검토 조건

- 개발 서버를 HTTPS(Cloudflare Tunnel 등)로 공개하게 되면: 공개 모드에서도 토큰을 유지할지 다시 본다
- 토큰이 틀린 요청 알림이 자주 보이면: 요청 제한이나 공개 모드에서 관리 화면 끄기를 다시 본다
- 공개 개발 서버를 오래 켜 두는 쓰임이 생기면: 운영 관리자 화면(ADR-0009 의 선택지 A)과 함께 다시 본다
