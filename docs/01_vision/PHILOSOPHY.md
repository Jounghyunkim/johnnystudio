## 1. 한 문장 정의

> **JohnnyStudio 는 정현 님이 만든 모든 것(소프트웨어·영상·사진·글·하드웨어)을 한곳에 모아 보여 주고,
> 바로 써 보게 하고, 함께 일하는 셀프 호스팅 스튜디오다.**

사이트의 대표 문구(히어로): **"만든 것을 한곳에, 바로 쓸 수 있게."** `[확인 필요]`

## 2. 왜 존재하는가 (미션)

흩어진 작업을 한곳에 모아, **누구나 쉽게 발견하고, 바로 쓰고, 필요하면 함께 일할 수 있게** 한다.
작업은 YouTube·GitHub·블로그·여러 서버에 흩어져 있다. 그래서 "어떤 일을 해 온 사람인가"를 한 번에 보여 주기 어렵다.

## 3. 어디로 가는가 (비전)

과거·현재·미래의 작업이 계속 쌓여 가는 **디지털 자아**를 만든다. 방문자·사용자·의뢰인은 각자 필요한 것을 바로 얻는다.
이 모든 것이 **스스로 소유한 인프라** 위에서 돈다.

## 4. 핵심 가치·원칙

| 가치 | 뜻 | 실제 행동 |
|---|---|---|
| **Digital Twin & Life Log** | 모든 궤적을 기록한다 | 작품마다 날짜·맥락·상태를 남긴다. 작품과 마일스톤을 하나의 타임라인으로 잇는다 |
| **Sovereignty & Self-Hosting** | 인프라와 데이터의 주도권 | 콘텐츠 원본은 저장소의 파일이다. 홈랩에서 운영한다. 외부 플랫폼은 배포 채널로만 쓴다 |
| **User-Centric Accessibility** | 무마찰 접근과 개인화 | 공개 기능은 로그인 없이 쓴다. 두 번의 클릭 안에 원하는 작품에 닿는다. 즐겨찾기는 로그인 없이도 된다 |
| **Seamless Collaboration** | 끊김 없는 협업 | 요청 → 작업 → 검수 → 납품을 한곳에 이력으로 남긴다. 의뢰인에게 GitHub 계정을 요구하지 않는다 |
| **Trust by Design** | 신뢰가 기본 | 다운로드마다 체크섬과 변경 내역을 공개한다. 외부 코드는 격리해서 실행한다. 방문자를 추적하지 않는다 |

## 5. 무엇을 하는가

- **작품 유형**: 웹 서비스, 데스크톱 툴, 웹 패키지, 영상, 사진, 글, 하드웨어 (ideation §3-1)
- **현재**: [Arkurator](https://arkurator.net), 파일 기반 지식 관리 + RAG AI 에이전트
- **등록 대기 (초안)**: 하드웨어 모니터링 앱, SSH 터미널 클라이언트, Skill Hub, 로봇 프로젝트. 내용을 채워야 한다 `[확인 필요]`
- **하지 않는 것**: ideation §8 참고 (공개 자료의 회원가입 강요, 범용 SNS 기능, 결제 등)

## 6. 누구를 위한가

| 방문자 | 기대하는 것 | 우선순위 (제안) |
|---|---|---|
| 잠재 의뢰인·협업자 | 실력과 신뢰 확인, 의뢰 방법 | ★★★ |
| 도구 사용자 | 툴을 찾아 바로 쓰기·받기 | ★★★ |
| 기존 의뢰인 | 결과물 확인, 피드백 (Phase 3) | ★★ |
| 일반 방문자·지인 | 어떤 일을 해 온 사람인가 | ★★ |

우선순위는 `[확인 필요]` (ideation §9-2).

## 7. 말투와 인상 (톤앤매너)

- **인상**: 세련되고, 미니멀하고, 전문적이다. 개발자이자 크리에이터. `[확인 필요]`
- **말투**: 짧은 문장, 합니다체. 과장하지 않고 사실과 숫자로 말한다. 기능보다 "방문자가 할 수 있는 일"을 먼저 말한다.
- **피할 것**: 과장된 마케팅 문구, 설명 없는 전문 용어, 한 화면에 너무 많은 정보
- **시각**: 다크 테마(기본, 밝은 테마 선택 가능), 강조색 하나, 미니멀 아이콘, 넉넉한 여백 ([03_design/DESIGN_SYSTEM.md](../03_design/DESIGN_SYSTEM.md))

## 8. 포털이 할 일

- **방문자가 1분 안에 알아야 할 것**: 무엇을 만드는 곳인지, 대표 작품이 무엇인지, 바로 써 볼 수 있다는 것
- **방문자가 다음에 하길 바라는 행동**: 작품 실행·다운로드, 즐겨찾기, 의뢰 문의
- **성공 기준**: ideation §7 의 단계별 지표 (Phase 1: 홈에서 상세까지 2클릭, 실행·다운로드 수, 의뢰 문의 수)
