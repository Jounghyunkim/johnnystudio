### 1. 개발 철학 (Development Philosophy)

* **Digital Twin & Life Log (디지털 자아와 삶의 기록):** 과거의 흔적부터 현재의 최신 프로젝트(AI 에이전트, ARKURATOR 등)까지 정현 님의 모든 궤적을 담아내는 공간.
* **Sovereignty & Self-Hosting (데이터 주권과 독립성):** 미니 PC 등 홈 랩(Home Lab) 환경을 활용해 인프라 주도권을 쥐고 플랫폼 종속에서 벗어난 아지트 구축.
* **User-Centric Accessibility (사용자 중심의 무마찰 접근과 개인화):** 방대한 자료 속에서도 방문자가 자신이 원하는 자료에 즉시 도달할 수 있도록 진입 장벽을 낮추고, 즐겨찾기 기반의 맞춤형 뷰를 제공.
* **Seamless Collaboration (끊김 없는 비즈니스 협업):** 프리랜서로서 창출한 결과물을 안전하게 전달하고, GitHub처럼 효율적이고 명확하게 의뢰인과 소통할 수 있는 폐쇄형/개방형 하이브리드 작업 환경 지향.

### 2. 상위 컨셉 (High-Level Concepts)

* **Unified Asset Library (다목적 에셋 라이브러리):**
* **다양한 포맷 지원:** 윈도우 실행 파일(.exe), 단독 웹사이트 패키지(.zip 또는 샌드박스 임베딩), 유튜브 영상, 사진 갤러리, 블로그 링크 등 형태가 다른 모든 산출물을 규격화된 카드 UI로 전시합니다.
* **원클릭 론처 & 다운로드:** 웹 서비스는 바로 실행되게, 데스크톱 툴은 즉시 다운로드 되게 연결하여 앱스토어와 같은 경험을 줍니다.


* **Personalized Dashboard ('My Studio' 뷰):**
* 로그인한 사용자에게는 방대한 전체 갤러리 대신, 본인이 '즐겨찾기(Star/Bookmark)'한 항목들을 최상단에 배치하는 대시보드 화면을 제공하여 자주 쓰는 툴에 빠르게 접근하도록 돕습니다.


* **Client Project Room (의뢰인 전용 워크스페이스):**
* 작업을 의뢰한 사람들(클라이언트)이 로그인하고 들어올 수 있는 독립된 포털입니다.
* **결과물 확인:** 프리랜서로서 작업한 맞춤형 결과물을 이 공간에 업로드하여 의뢰인이 바로 확인하고 다운로드할 수 있습니다.
* **GitHub-like Communication:** 이슈(Issue) 트래킹이나 PR(Pull Request) 형태의 댓글 스레드 기능을 도입하여, 결과물에 대한 피드백, 수정 요청, 진행 상황 공유를 한곳에서 이력으로 남기며 소통합니다.


* **Interactive AI Hideout & Minimalist Design:**
* Tailwind CSS 기반의 **세련된 다크 테마와 미니멀리스트 아이콘**을 적극 사용하여 트렌디한 감각을 줍니다.
* 'JohnnyBot' AI 에이전트가 상주하여 흩어진 프로젝트들을 안내하고 추천해 줍니다.



### 3. 기술 스택 및 아키텍처 (Tech Stack & Architecture)

기존 스택에 대용량 파일 처리, 인증, 실시간 소통 기능을 추가한 아키텍처입니다.

| 구분 | 기술 스택 | 설명 및 적용 방안 |
| --- | --- | --- |
| **Frontend** | React / Next.js, Tailwind CSS | 다크 테마 기반 반응형 UI. 사용자 대시보드 및 클라이언트 포털의 복잡한 상태 관리. |
| **Backend** | Python (FastAPI) | 메인 비즈니스 로직, 클라이언트 권한 관리, 소통 채널(댓글/피드백) API 제공. |
| **Database** | PostgreSQL, Redis | 사용자 정보, 즐겨찾기 상태, 클라이언트 프로젝트 진행 상태 및 댓글 이력 저장. |
| **Storage** | MinIO (Self-hosted S3 API) | 대용량 `.exe` 패키지, 웹사이트 압축 파일, 고해상도 미디어의 안정적인 저장 및 배포. |
| **Auth & Comms** | NextAuth (JWT), WebSockets | 개인화(즐겨찾기) 및 클라이언트 구분을 위한 인증. 클라이언트와의 실시간 알림/채팅. |
| **AI 연동** | LangGraph, ChromaDB | 프로젝트 검색 및 추천을 돕는 'JohnnyBot' 지식베이스 구축. |
| **Infrastructure** | 미니 PC 홈 랩, Docker, Cloudflare | Cloudflare Tunnel을 통한 외부 도메인 보안 연결. |

### 4. 단계별 구현 계획 (Implementation Phases)

**Phase 1: 통합 갤러리 및 다목적 에셋 라이브러리 (기반 구축)**

* 미니멀리스트 다크 테마 기반의 랜딩 페이지 및 갤러리 UI 퍼블리싱.
* `.exe` 다운로드, 유튜브 링크, 블로그 아웃링크, 이미지 뷰어 등 포맷별로 다르게 반응하는 뷰어/다운로더 컴포넌트 개발.
* MinIO 스토리지를 구축하여 무거운 정적 파일들 호스팅 시작.

**Phase 2: 사용자 인증 및 개인화 대시보드 (개인화)**

* 회원가입/로그인 시스템 연동 (Google OAuth 등 소셜 로그인 포함).
* 각 창작물 썸네일에 '즐겨찾기(⭐)' 기능 추가.
* 로그인 유저 진입 시, 즐겨찾기한 항목이 위젯 형태로 우선 정렬되는 맞춤형 'My Studio' 대시보드 화면 구현.

**Phase 3: 클라이언트 전용 워크스페이스 (B2B 협업)**

* 초대받은 클라이언트만 접근할 수 있는 '프로젝트 룸(Project Room)' 권한 분리 개발.
* 프리랜서 작업 산출물을 특정 클라이언트에게만 비공개로 할당하는 업로드 기능 구현.
* GitHub 이슈(Issue)와 유사한 형태의 피드백 게시판 개발 (상태값: 대기중/작업중/완료, 스레드형 댓글 통신).

**Phase 4: 동적 라이프로그 연동 및 AI 에이전트 (고도화)**

* 외부 플랫폼(GitHub, 블로그, 유튜브) 최신 피드 자동화 크롤링 연동.
* ChromaDB에 에셋 정보를 모두 벡터라이징하여 탑재한 대화형 어시스턴트 'JohnnyBot' 활성화 (방문자에게 적합한 툴 추천 및 클라이언트 FAQ 응대).
