JohnnyStudio는 공개 자료를 **로그인 없이** 쓸 수 있게 만듭니다. 회원 가입은 선택이고, 가입할 때 받는 정보는 **이메일 주소와 비밀번호**뿐입니다.

## 1. 받는 정보와 쓰는 곳

| 정보 | 쓰는 곳 | 보관 기간 |
|---|---|---|
| 이메일 주소 | 회원 구분(로그인 아이디), 가입 인증·비밀번호 재설정 메일 보내기 | 탈퇴할 때까지 |
| 비밀번호 (변환한 값) | 로그인 | 탈퇴할 때까지 |
| 가입 시각, 마지막 로그인 시각, 비밀번호를 바꾼 시각 | 계정 화면 표시 | 탈퇴할 때까지 |
| 로그인 세션 (쿠키) | 로그인 상태 유지 | 30일, 또는 로그아웃할 때까지 |
| 메일 링크 요청 기록 | 링크 확인, 짧은 시간에 너무 많은 요청 막기 | 하루 |
| 로그인 실패 기록 (이메일, 접속 IP 를 변환한 값, 시각) | 비밀번호를 여러 번 틀리면 잠시 막기 | 하루 |

- **비밀번호는 원래 값을 저장하지 않습니다.** 되돌릴 수 없게 변환한 값(scrypt 해시)만 저장하므로 운영자도 비밀번호를 알 수 없습니다. 잊었을 때는 메일 링크로 새로 정합니다.
- 메일 링크와 로그인 세션도 원래 값을 저장하지 않고, 되돌릴 수 없게 변환한 값(해시)만 저장합니다.
- 요청 횟수를 세려고 접속 IP 를 쓰지만, IP 를 그대로 저장하지 않고 되돌릴 수 없게 변환한 값만 하루 동안 남깁니다.
- 이름, 전화번호는 받지 않습니다.

## 2. 쿠키

로그인하면 로그인 상태를 유지하는 쿠키 하나를 씁니다. 페이지의 스크립트가 읽을 수 없는 쿠키(httpOnly)이고, 다른 사이트에는 보내지지 않습니다.
광고·분석·추적용 쿠키는 쓰지 않습니다. 로그인하지 않으면 쿠키를 만들지 않습니다.

즐겨찾기(My Studio)는 서버가 아니라 이 브라우저에만 저장됩니다.
로그인 화면에서 **아이디(이메일) 기억하기**를 켜면 이메일 주소가 이 브라우저에만 저장되고 서버로는 보내지 않습니다. 비밀번호는 저장하지 않습니다.
체크를 끄고 로그인하거나 탈퇴하면 지워집니다. 화면 테마(밝게·어둡게) 선택도 이 브라우저에만 저장됩니다.

## 3. 다른 곳에 맡기는 일

- **메일 발송**: 로그인 링크 메일은 메일 발송 업체를 거쳐 보냅니다. 업체에는 받는 사람 주소와 메일 내용만 전달됩니다. <!-- TODO(content): 업체 이름 -->
- **네트워크**: 사이트는 Cloudflare 를 거쳐 전달됩니다. 접속 기록이 Cloudflare 의 정책에 따라 처리될 수 있습니다.

그 밖의 곳에 개인정보를 주거나 팔지 않습니다.

## 4. 탈퇴와 삭제
