JohnnyStudio는 공개 자료를 **로그인 없이** 쓸 수 있게 만듭니다. 회원 가입은 선택이고, 가입할 때 받는 정보는 **이메일 주소와 비밀번호**뿐입니다.

## 1. 받는 정보와 쓰는 곳

| 정보 | 쓰는 곳 | 보관 기간 |
|---|---|---|
| 이메일 주소 | 회원 구분(로그인 아이디), 가입 인증·비밀번호 재설정 메일 보내기 | 탈퇴할 때까지 |
| 비밀번호 (변환한 값) | 로그인 | 탈퇴할 때까지 |
| 가입 시각, 마지막 로그인 시각, 비밀번호를 바꾼 시각 | 계정 화면 표시 | 탈퇴할 때까지 |
| 로그인 세션 (쿠키) | 로그인 상태 유지 | 30일, 또는 로그아웃할 때까지 |
| 메일 링크 요청 기록 | 링크 확인, 짧은 시간에 너무 많은 요청 막기 | 하루 |
| 로그인 실패 기록 (이메일, 접속 IP 를 변환한 값, 시각) | 비밀번호를 여러 번 틀리면 잠시 막기 | 하루 |
| **Store**: 표시 이름, 이용약관 동의 시각·판, 만 14세 이상 확인 | 앱 화면의 '올린 사람' 표시, 약관 동의 기록 | 탈퇴할 때까지 |
| **Store**: 올린 앱 (파일, 이름·소개·설명, 파일에서 읽은 정보, 검사·검토 결과, 내려받은 횟수) | 앱을 보여 주고 내려받게 하기, 검토·바이러스 검사 | 앱을 지우거나 탈퇴할 때까지 (반려된 파일은 바로 지운다) |
| **Store·Showroom 소개 자료**: 기능·사용 방법·질문·링크, 소개 그림, 회원이 적은 개발자 이름·저작권 정보·웹 사이트·지원 연락처(주소 또는 이메일)·개인정보처리방침 주소 | 앱·서비스 화면에 공개 | 고치거나, 앱·서비스를 지우거나, 탈퇴할 때까지 |
| **Store**: 올리다 만 파일, 올린 횟수 기록 | 하루 업로드 횟수·용량 한도 | 파일은 하루, 기록은 이틀 |
| **Store**: 신고 (사유, 내용, 적어 준 연락처, 회원인지 여부, 접속 IP 를 변환한 값) | 신고 처리, 짧은 시간에 너무 많은 신고 막기 | 처리한 뒤 1년 [확인 필요] |
| **Showroom**: 소개한 서비스 (이름·주소·소개·설명·분류, 아이콘·화면 그림, 검토 결과) | 서비스를 보여 주기, 검토 | 소개를 지우거나 탈퇴할 때까지 |
| **Showroom**: 신고 (Store 신고와 같은 항목) | 신고 처리 | 처리한 뒤 1년 [확인 필요] |

- **비밀번호는 원래 값을 저장하지 않습니다.** 되돌릴 수 없게 변환한 값(scrypt 해시)만 저장하므로 운영자도 비밀번호를 알 수 없습니다. 잊었을 때는 메일 링크로 새로 정합니다.
- 메일 링크와 로그인 세션도 원래 값을 저장하지 않고, 되돌릴 수 없게 변환한 값(해시)만 저장합니다.
- 요청 횟수를 세려고 접속 IP 를 쓰지만, IP 를 그대로 저장하지 않고 되돌릴 수 없게 변환한 값만 하루 동안 남깁니다.
- 이름, 전화번호는 받지 않습니다.
- Store·Showroom 의 **표시 이름은 앱·서비스 화면에 공개**됩니다. 이메일 주소는 다른 사람에게 보이지 않고, 운영자만 검토·신고 처리에 씁니다.
- 소개 자료에 직접 적은 **개발자 이름·지원 연락처(이메일 포함)는 누구나 볼 수 있게 공개**됩니다. 공개해도 되는 연락처만 적어 주세요. 소개 자료 파일(zip·md)은 브라우저에서만 읽고 서버로 보내지 않습니다. 서버는 정리한 글과 그림(다시 그린 것)만 받습니다.
- Showroom 의 서비스 링크를 누르면 그 바깥 사이트로 이동합니다. 사이트는 어느 링크를 눌렀는지 기록하지 않습니다. 이동한 뒤의 정보 처리는 그 사이트의 방침을 따릅니다.
- Store 에 올린 파일은 운영 서버 안에서만 바이러스 검사(ClamAV)를 합니다. 외부 검사 서비스에 보내지 않습니다.
  앱 화면의 'VirusTotal에서 찾아보기'는 방문자가 직접 여는 링크이고, 사이트는 아무것도 보내지 않습니다.

## 2. 쿠키

로그인하면 로그인 상태를 유지하는 쿠키 하나를 씁니다. 페이지의 스크립트가 읽을 수 없는 쿠키(httpOnly)이고, 다른 사이트에는 보내지지 않습니다.
광고·분석·추적용 쿠키는 쓰지 않습니다. 로그인하지 않으면 쿠키를 만들지 않습니다.

즐겨찾기(My Studio)는 서버가 아니라 이 브라우저에만 저장됩니다.
로그인 화면에서 **아이디(이메일) 기억하기**를 켜면 이메일 주소가 이 브라우저에만 저장되고 서버로는 보내지 않습니다. 비밀번호는 저장하지 않습니다.
체크를 끄고 로그인하거나 탈퇴하면 지워집니다. 화면 테마(밝게·어둡게) 선택도 이 브라우저에만 저장됩니다.

- **네트워크**: 사이트는 Cloudflare 를 거쳐 전달됩니다. 접속 기록이 Cloudflare 의 정책에 따라 처리될 수 있습니다.

그 밖의 곳에 개인정보를 주거나 팔지 않습니다.

## 4. 탈퇴와 삭제

[계정](/account/) 화면에서 언제든 탈퇴할 수 있습니다. 탈퇴하면 계정(비밀번호 포함), 로그인 세션, 남아 있는 메일 링크, 로그인 실패 기록,
Store 에 올린 앱·파일, Showroom 에 소개한 서비스·그림, 표시 이름이 **바로** 지워집니다. 내가 한 신고와 내 앱에 들어온 신고의 처리 기록은 계정과의 연결을 끊고 남깁니다.
