SentinelLite-AV는 Rust로 만든 가벼운 Windows 악성코드 방어 도구입니다. 백그라운드 서비스가 파일을 검사하고 프로세스 행위를 감시하며, 트레이 앱에서 상태 · 경고 · 격리 항목을 확인하고 파일을 직접 검사할 수 있습니다.

※ 초기 버전(0.1.0)입니다. 함께 제공되는 탐지 규칙은 EICAR 테스트 파일과 스크립트 휴리스틱 2종(YARA), 행위 규칙 5종(Sigma)으로 범위가 좁습니다. Windows 보안(Microsoft Defender)을 대체하지 않으니 함께 사용하세요.

## 구성

- 서비스 (sentinellite-svc.exe) — Windows 서비스 "SentinelLiteAV"로 등록되어 Windows와 함께 시작합니다.
- 트레이 앱 (SentinelLite) — 개요 · 경고 · 격리 · 검사 탭. 자체 권한 없이 서비스에 요청만 보냅니다.
- 명령줄 도구 (sentinellite-ctl.exe) — 파일 · 폴더 검사, 서비스 상태와 경고 조회, 격리 관리, 규칙 다시 읽기

## 탐지

- 파일 검사: YARA-X 엔진으로 새로 만들어진 파일, 실행된 프로그램, 프로세스가 불러오는 모듈을 검사합니다. 검사 결과는 캐시하고, 신뢰할 수 있는 서명이 있는 파일은 빠르게 통과시킵니다.
- 압축 파일: ZIP 계열(ZIP, OOXML 문서, JAR, APK) 내부를 검사합니다.
- 행위 감시: ETW로 프로세스 생성과 레지스트리 쓰기를 수집해 Sigma 규칙으로 평가합니다 (숨김 PowerShell + 인코딩된 명령, 섀도 복사본 삭제, Office가 스크립트 호스트 실행, 사용자 쓰기 가능 경로를 가리키는 자동 실행 키).
- 스크립트 내용: 스크립트 호스트가 AMSI에 넘긴 버퍼를 YARA 규칙으로 검사합니다.
- 수동 검사: 트레이 앱의 검사 탭, 또는 sentinellite-ctl svc scan <경로>

## 대응

- 기본 설정(enforce)에서는 YARA로 탐지된 파일을 격리하고, 그 파일에서 시작된 프로세스를 종료합니다.
- 행위(Sigma) 규칙만 일치한 경우에는 프로세스를 일시 중지하고 메모리를 검사한 뒤, 거기서 탐지될 때만 종료합니다. 행위 규칙만으로는 프로세스를 종료하지 않습니다.
- 중요한 시스템 프로세스는 일시 중지하거나 종료하지 않습니다.
- 격리한 파일은 AES-256-GCM으로 암호화해 보관하고(키는 DPAPI로 보호), 관리자 권한으로 복원하거나 삭제할 수 있습니다.
- 경고만 기록하게 하려면 %ProgramData%\SentinelLite\config.json 에 {"response": "alert"} 를 저장한 뒤 서비스를 다시 시작하세요.

## 설치 안내

- 설치에 관리자 권한이 필요합니다. Program Files에 설치하고 서비스를 등록 · 시작합니다.
- 제거하면 서비스 등록도 함께 삭제됩니다. 설정 · 로그 · 격리 보관소(%ProgramData%\SentinelLite)는 격리된 파일을 잃지 않도록 남겨 둡니다.
- 프로그램이 실행되기 전에 막는 커널 미니필터 드라이버는 아직 테스트 서명 단계라 이 설치 파일에 들어 있지 않습니다. 드라이버가 없으면 실행을 미리 보류하지는 못하고, 실행 직후 검사해 대응합니다.
- 트레이 앱은 Windows 시작 시 자동으로 실행되지 않습니다. 시작 메뉴에서 실행하세요. 보호는 트레이 앱과 관계없이 서비스가 수행합니다.
- 격리 항목 복원 · 삭제와 규칙 다시 읽기는 트레이 앱을 관리자 권한으로 실행했을 때만 됩니다.

## 안전 설계

- 검사가 제한 시간(200ms)을 넘기거나 파일을 읽을 수 없으면 정상 파일로 처리해 시스템이 멈추지 않게 합니다.
- 서비스 대기 시 메모리 약 35MB, CPU 0.1% 미만 (테스트 VM에서 측정한 값)

## 시스템 요구 사항

Windows 10/11 (x64), WebView2 런타임 (없으면 설치 중에 자동으로 내려받습니다)
