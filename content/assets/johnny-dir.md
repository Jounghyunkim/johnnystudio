Johnny-Dir는 Windows 탐색기의 느린 반응을 해결한 4분할 파일 관리자입니다. 여러 폴더를 한 화면에 나란히 열어 두고, 끌어다 놓기로 복사 · 이동하고, 스페이스 한 번으로 파일 내용을 미리 봅니다.

## 한 화면에 폴더 4개

단일 · 좌우 · 상하 · 3분할 · 4분할 화면을 Alt+1~4로 바로 바꿉니다. 패널마다 탭, 주소창, 필터, 뒤로/앞으로 기록이 따로 있고, 경계선을 끌어 크기를 조절합니다.

## 수만 개 파일도 즉시

Win32 API로 폴더를 직접 읽고, 보이는 줄만 그려서 파일이 아주 많은 폴더도 바로 열립니다. 폴더 용량은 백그라운드에서 계산해 목록에 채워 넣습니다.

## 타이핑하면 바로 필터

폴더를 보다가 글자를 입력하면 그 자리에서 목록이 걸러집니다. Ctrl+P 커맨드 팔레트로 즐겨찾기, 드라이브, 레이아웃, 경로 이동을 키보드만으로 실행합니다.

## 스페이스로 빠른 미리보기

이미지, 동영상, 음악, PDF, 마크다운, 코드(문법 강조)를 앱 안에서 바로 봅니다. 한글 EUC-KR(CP949) 텍스트도 깨지지 않습니다. 방향키로 다음 파일로 넘어갑니다.

## 멈추지 않는 파일 작업

복사 · 이동 · 휴지통 삭제 · ZIP 압축과 풀기를 작업 큐에서 처리하고, 진행률 · 속도 · 남은 시간을 하단 트레이에 보여 줍니다. 작업 중에도 계속 탐색할 수 있고, 언제든 취소할 수 있습니다.

## 패널 사이 끌어다 놓기

파일을 다른 패널, 폴더, 탭, 주소창, 사이드바로 끌어 놓습니다. 같은 드라이브는 이동, 다른 드라이브는 복사하는 Windows 탐색기 방식을 따르고, Ctrl / Shift로 바꿀 수 있습니다.

## 작업 공간 저장

열어 둔 패널의 경로, 탭, 정렬을 프리셋으로 저장하고 한 번에 불러옵니다. 앱을 다시 켜면 마지막 화면 그대로 시작합니다.

## 테마 16종

기본 Midnight를 비롯해 Dracula, Nord, One Dark, 밝은 테마, 한지, 벚꽃, 별이 빛나는 밤, 오로라, 심해 등 그림 배경 테마를 고를 수 있습니다.

## Windows와 자연스럽게

Windows 탐색기 우클릭 메뉴, 시스템 파일 아이콘, 속성 창, 터미널 열기를 그대로 씁니다. 다른 프로그램이 파일을 바꾸면 목록이 자동으로 새로 고쳐집니다. F2 이름 바꾸기, Del 삭제, Ctrl+C/X/V 등 키보드만으로 모든 작업을 할 수 있습니다.

## 개인정보를 수집하지 않습니다

회원 가입, 광고, 사용 통계 수집이 없고 인터넷에 연결하지 않습니다. 모든 설정은 사용자 PC에만 저장됩니다.

## 시스템 요구 사항

Windows 10/11 (x64), WebView2 런타임 (없으면 설치 중에 자동으로 내려받습니다)

설치에 관리자 권한이 필요합니다. 앱 화면은 한국어로 제공됩니다.
