Screen-REC은 화면 녹화, 스크린샷, 일정 간격 캡처와 타임랩스 제작을 한 곳에서 처리하는 Windows용 화면 기록 도구입니다. 단축키 한 번으로 가볍게 시작하고, 결과물은 깔끔한 MP4와 이미지로 남깁니다.

## 화면 녹화

- 전체 모니터, 특정 창, 마우스로 드래그한 영역 중에서 녹화할 대상을 고를 수 있습니다.
- Windows Graphics Capture로 화면을 받아 H.264 MP4로 바로 인코딩합니다.
- NVIDIA NVENC, Intel Quick Sync, AMD AMF 하드웨어 인코더를 자동으로 감지해 CPU 부담을 줄입니다. 지원하지 않는 PC에서는 소프트웨어 인코더(x264)를 씁니다.
- 프레임레이트(10~60fps), 화질, 해상도 비율을 설정할 수 있습니다.
- 시스템 사운드(스피커 출력)와 마이크를 함께 녹음합니다.
- 일시정지와 다시 시작을 지원합니다. 멈춘 시간은 영상에 들어가지 않습니다.
- 시작 카운트다운을 설정할 수 있고, 녹화하는 동안 창을 자동으로 숨길 수 있습니다.

## 스크린샷

- 버튼이나 전역 단축키(기본값 Ctrl+Shift+S)로 지금 화면을 바로 PNG 또는 JPG로 저장합니다.
- 다른 프로그램을 쓰는 중에도 단축키가 동작합니다.

## 일정 간격 캡처와 타임랩스

- 1초, 5초, 1분처럼 정한 간격마다 화면을 이미지로 자동 저장합니다.
- 캡처를 멈추면 모은 이미지를 타임랩스 MP4 영상으로 자동으로 합칩니다.
- 이미 있는 이미지 폴더로도 타임랩스를 만들 수 있습니다.
- 작업 과정 기록, 디자인 · 코딩 진행 기록, 장시간 모니터링에 알맞습니다.

## 저장된 파일 관리

- 녹화 영상, 타임랩스, 스크린샷, 인터벌 이미지 폴더를 최신순으로 한눈에 봅니다.
- 종류별 필터와 이름 검색을 지원합니다.
- 여러 파일을 골라 휴지통으로 옮기거나 영구 삭제할 수 있습니다.

## 편의 기능

- 전역 단축키는 원하는 키 조합으로 바꿀 수 있습니다.
- 창을 닫아도 시스템 트레이에서 계속 실행되며, 트레이 메뉴로 녹화 · 캡처를 제어합니다.
- FFmpeg 인코딩 진행 상황과 캡처 로그를 실시간 콘솔로 보여 줍니다.
- 모든 설정은 자동으로 저장됩니다.

## 개인 정보

- 녹화한 영상과 이미지는 사용자가 지정한 폴더에만 저장되며, 외부 서버로 전송되지 않습니다.
- 계정 가입이나 로그인이 필요 없고, 광고와 사용 통계 수집이 없습니다.

## 시스템 요구 사항

Windows 10/11 (x64), WebView2 런타임 (없으면 설치 중에 자동으로 내려받습니다)

설치에 관리자 권한이 필요합니다.

이 앱은 FFmpeg(GPL v3)를 함께 제공합니다. 라이선스는 설치 폴더의 resources\FFMPEG-LICENSE.txt를, 소스 코드는 https://ffmpeg.org 를 참고하세요.
