SmartFolder Organizer는 Downloads를 비롯한 여러 폴더를 하위 폴더까지 스캔해 중복 파일을 제거하고, 파일 분류 · 날짜 · 이름이 비슷한 그룹 · 사용자 규칙에 따라 폴더 구조와 파일명을 정리하는 Windows 데스크톱 앱입니다.

정리는 항상 미리보기(Dry-Run) → 변경 전/후 트리 확인 → 확인 → 실행 순서로만 진행됩니다. 확인하기 전에는 어떤 파일도 바뀌지 않고, 실행한 작업은 한 번에 되돌릴 수 있습니다.

## 사용 순서

1. 폴더 선택 — Downloads 버튼, 폴더 추가, 또는 창으로 폴더를 끌어다 놓기
2. 스캔 시작 — 중복 파일과 정리 계획을 계산합니다. 이 단계에서는 파일이 바뀌지 않습니다.
3. 미리보기 확인 — 변경 전 / 변경 후 트리가 나란히 표시됩니다. 체크박스로 개별 파일 · 폴더를 실행에서 빼고, 그룹 폴더 이름을 바꿀 수 있습니다.
4. 선택 항목 실행 — 최종 확인 창에서 확인을 눌러야 실제로 변경됩니다.
5. 작업 이력 — 실행한 배치를 골라 모든 파일을 원래 위치로 복원합니다.

## 중복 제거

- "이름 (1)", "이름 - 복사본", "이름_copy" 같은 접미사를 뗀 이름과 확장자가 같고, 크기 · 첫 4KB 해시 · 전체 BLAKE3 해시가 모두 같은 파일만 중복으로 판정합니다.
- 원본 1개를 남기고 나머지는 휴지통으로 보냅니다.
- Loose 모드에서는 이름은 같지만 내용이 다른 수정본 가운데 최신본만 남기고 나머지를 _Versions 폴더로 모읍니다.

## 정리 방식 (프리셋)

- topic (기본): 이름이 비슷한 파일은 그룹 폴더로, 나머지는 분류/연-월 폴더로
- category: 분류별 · category-topic: 분류 안에서 그룹별
- date: 연/월 폴더 · extension: 확장자별
- dedup-only: 폴더 구조는 그대로 두고 중복만 제거
- tidy: 폴더 구조를 유지하면서 비슷한 폴더 합치기 + 비슷한 파일 이름 통일

## 비슷한 것끼리 묶기와 이름 통일

- 날짜와 버전 표기(v1.0, 최종, 초안, final …)를 뺀 핵심 단어가 겹치고 이름 유사도가 기준 이상인 파일을 확장자와 관계없이 하나의 그룹 폴더로 모읍니다.
- 날짜는 파일명 속 날짜 → 이미지 EXIF 촬영일 → 수정일 순으로 사용합니다.
- 비슷한 폴더 합치기: "회의록 (1)", "회의록_최종" → "회의록". 숫자 · 날짜 · 버전이 다른 폴더는 합치지 않습니다.
- 파일 이름 통일: "20261103 신규사업계획서 v2.docx" → "신규사업계획서_2026-11-03_v2.docx"
- 사용자 규칙: 파일명 단어/정규식, 분류, 확장자, 용량, 경과일 조건으로 이동 또는 휴지통 동작을 지정합니다.

## 안전 장치

- .git, node_modules, .venv, package.json, *.sln 등이 있는 폴더는 보호된 프로젝트로 보고 내부를 건드리지 않습니다. 숨김/시스템 파일과 다운로드 중인 파일도 제외합니다.
- 삭제는 영구 삭제가 아니라 Windows 휴지통 이동입니다.
- 대상 위치에 같은 이름의 파일이 있으면 덮어쓰지 않고 번호를 붙입니다.
- 모든 작업은 실행 전에 기록되므로, 실행 도중 앱이 종료되어도 되돌릴 수 있습니다.
- Watch 모드는 폴더 변경을 감지해 미리보기만 새로 만들며, 파일을 자동으로 옮기지 않습니다.
