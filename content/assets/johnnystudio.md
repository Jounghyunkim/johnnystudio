JohnnyStudio는 소프트웨어·영상·사진·글·하드웨어 작업을 한곳에 모은 셀프 호스팅 스튜디오입니다. 둘러보고, 바로 실행하거나 내려받고, 필요하면 함께 일할 수 있습니다.

### 둘러보기: Library와 Life Log
**Library**는 형태가 다른 작품을 같은 자리에서 찾는 곳입니다. 이름·설명·태그로 검색하고 유형으로 거를 수 있으며, 검색 상태가 주소에 남아서 그대로 공유할 수 있습니다. 지금은 웹 서비스와 Windows 데스크톱 앱이 공개되어 있고, 안드로이드 앱·웹 패키지·영상·사진·글·하드웨어 유형은 준비 중입니다.

**Life Log**는 무엇을 언제 시작했고 무엇을 바꾸고 옮겨 왔는지를 작품과 이정표로 이어 보여 주는 타임라인입니다.

### 바로 쓰기: 실행과 내려받기
웹 서비스는 작품 화면에서 바로 실행합니다. Windows 프로그램은 내려받기 전에 버전·크기·필요 환경을 보여 주고, 파일마다 SHA-256 체크섬과 확인 명령(`Get-FileHash`)을 함께 공개합니다. 코드 서명이 없는 파일이면 Windows가 경고(SmartScreen)를 띄울 수 있다는 점도 미리 알려 줍니다.

### Store와 Showroom
**Store**는 JohnnyStudio가 만든 Windows 앱과 회원이 직접 만든 프로그램을 한곳에서 내려받는 곳입니다. 회원이 올린 파일은 서버 안에서 ClamAV로 바이러스 검사를 하고, 운영자가 검토해 승인한 것만 공개합니다. 앱 화면에는 검사 결과, 코드 서명 여부, SHA-256 체크섬, VirusTotal 검색 링크가 있습니다. 다만 검사가 모든 위험을 찾아낸다고 보장하지는 않으므로, 믿을 수 있는 개발자의 앱인지 확인하고 설치해 주세요.

**Showroom**은 회원이 만든 웹 서비스를 소개하는 곳입니다. 운영자가 주소와 내용을 확인한 서비스만 공개하고, 서비스는 바깥 링크로 새 탭에서 엽니다. 사이트는 어느 링크를 눌렀는지 기록하지 않습니다.

Store와 Showroom은 같은 **소개 자료** 양식을 씁니다. 기능·화면 그림·사용 방법·자주 묻는 질문·만든 이 정보를 Microsoft Store 등록 항목과 같은 한도로 채우고, AI 코딩 도구용 프롬프트로 초안을 만든 뒤 md·zip 파일로 불러올 수 있습니다. 소개 자료 파일은 브라우저에서만 읽고 서버로 보내지 않습니다.

### 회원과 개인정보
둘러보기·실행·내려받기·즐겨찾기에는 가입이 필요 없습니다. 가입은 앱을 올리거나 서비스를 등록할 때만 필요합니다. 가입하면 이메일 주소와 되돌릴 수 없게 변환한 비밀번호 값을 저장하고, 이름과 전화번호는 받지 않습니다. Store·Showroom에 올릴 때 정한 표시 이름은 화면에 공개되지만, 이메일 주소는 다른 사람에게 보이지 않습니다. 자세한 내용은 [개인정보처리방침](https://johnnystudio.net/privacy/)에 있습니다.

### 운영 원칙
- **디지털 자아와 삶의 기록**: 모든 작업을 언제·왜 만들었는지와 함께 기록합니다.
- **데이터 주권과 독립성**: 집에 있는 홈랩 서버에서 직접 운영하고, 콘텐츠 원본은 파일로 두어 언제든 옮길 수 있습니다.
- **무마찰 접근과 개인화**: 공개 자료는 로그인 없이 바로 쓰고, 즐겨찾기로 나만의 화면을 만듭니다.
- **끊김 없는 협업**: 요청부터 검수, 납품까지 한곳에 이력으로 남깁니다.
- **신뢰가 기본**: 다운로드 파일의 체크섬과 변경 내역을 공개하고, 방문자를 추적하지 않습니다.

### 지금 준비 중인 것
의뢰인과 결과물을 주고받는 전용 공간(Client Room)은 준비 중입니다.
